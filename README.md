# kuis_edukasi
Petualangan Kuis Edukasi adalah aplikasi permainan kuis interaktif berbasis web untuk pelajar dengan tiga kategori pilihan yaitu Matematika, Bahasa Inggris, dan Pengetahuan Umum. Aplikasi ini dilengkapi efek suara internal, pengatur waktu, sistem skor, efek konfeti, serta penyimpanan skor otomatis
